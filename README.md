## 👤 About

I'm a Full Stack Developer with **5+ years of experience**, currently focused on **B2B SaaS products** built with React, Next.js, TypeScript, NestJS, GraphQL and Prisma. In my most recent role I was the technical owner of **two products in production** — responsible for architecture (Clean Architecture, SOLID), data modeling, GraphQL API design, and everything from the first commit to the deploy.

Before that I spent years in a very different arena: **high-traffic editorial platforms and e-commerce**, in PHP and WordPress. That's where I learned what breaks at scale — caching strategies, NGINX and Cloudflare tuning, indexing problems, Core Web Vitals — and where I shipped **30+ projects** end to end, plus custom plugins and themes with a genuinely modular architecture. I also implemented structured data (JSON-LD / Schema.org) that earned Rich Results and lifted organic CTR.

The through-line is that I like being close to the business problem. I've led a squad of four developers, set code standards, introduced CI/CD, and mentored juniors — but what I actually enjoy is translating a fuzzy business need into something shipped, tested and measurable. I hold a **BSc in Computer Science** and I'm currently doing a **postgraduate degree in Artificial Intelligence with a focus on LLMs**.
